# Contributing

This project welcomes improvements to the **fictional, browser-only restaurant POS demo**.

1. Fork the repository and make a focused feature branch.
2. Install Bun and run `bun install --frozen-lockfile`, `bun test`, and `bun run build`.
3. Test changes with the included dummy restaurant data, never with real customer information.
4. Open a pull request explaining behavior changes, test results, screenshots if relevant, and any data migration or breaking changes.

Please avoid changes that imply cloud synchronization, secure staff permissions, actual payment processing, or validated accounting unless those capabilities are actually implemented and tested. Do not commit generated builds, secrets, personal records, production backups, or proprietary third-party artwork.

Read [SECURITY.md](SECURITY.md) to report sensitive issues privately. Contributions are submitted under the terms of the [MIT License](LICENSE).
